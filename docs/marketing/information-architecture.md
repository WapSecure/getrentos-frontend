# Information architecture

The site map of the Sureground website as built on `dev` (12 Nov 2026, after #217). Read from `apps/web/app` (routes), `components/layout/Navigation.tsx` and `Footer.tsx`, `app/sitemap.ts`, `app/robots.ts` and each page's `generateMetadata`. It describes what exists; it is not a proposal. Indexing detail and monitoring live in `seo-monitoring.md`; keyword intent in `content-strategy.md`.

## 1. Public pages by intent

| Intent                | Pages                                                                                                                                        | Notes                                                                                                                  |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Brand and orientation | `/`, `/about`, `/pricing`                                                                                                                    | Homepage carries `Organization` and `WebSite` JSON-LD.                                                                 |
| Find a home or plot   | `/rent`, `/buy`, `/shortlets`, `/land`, `/developments`, `/estates`                                                                          | Market pages. First page rendered on the server with `ItemList` JSON-LD (rent, buy, short stays, land).                |
| Listing detail        | `/rent/[id]`, `/buy/[id]`, `/land/[id]`, `/shortlets/[id]`, `/developments/[id]`, `/collections/[slug]`                                      | Slug paths from `lib/listingSlug.ts`. Missing items return 404 + `noindex`.                                            |
| Area intent           | `/areas/[slug]`                                                                                                                              | Published only with at least 3 live rent and sale listings (`MIN_AREA_LISTINGS`); otherwise 404 + `noindex`.           |
| How it works, by role | `/renters`, `/buyers`, `/landlords`, `/sell`, `/agents`, `/home-management`                                                                  | Segment landing pages on the shared marketing components (D2 in `decisions.md`).                                       |

| Account entry         | `/login`, `/signup`, `/forgot-password`, `/role-selection`                                                                                   | `(auth)` group: `noindex, follow`, not in the sitemap.                                                                 |

## 2. Navigation

### Main nav (desktop, `lg` and up)

Fixed top bar, `aria-label="Main"`.

| Position | Content                                                                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Left     | Find links: **Buy**, **Rent**, **Short stays**, **Land** (hidden when the land marketplace is off), **Off-plan** (`/developments`). Then the **More** dropdown.              |
| Centre   | Logo (home).                                                                                                                                                                 |
| Right    | Signed out: **Sign in**, theme switch, **Get started** (`/signup`). Signed in: role dashboard link and **Sign out**. A search icon (`aria-label="Search homes"`) to `/rent`. |

Current page links carry `aria-current="page"` and an underline.

### More menu

In order, each with a one-line hint: **Diaspora Invest** (only when the service is on), **Sell**, **Let** (`/landlords`), **Estates**, **Detty December**, **Property management** (`/home-management`), **Realtors and agencies** (`/agents`), **Pricing**, **About**.

Not linked from the main nav: `/renters`, `/buyers`, `/resources`, `/areas/*`. They are reached from the footer, the homepage and in-page links.

### Mobile menu (below `lg`)

A **Menu** button (`aria-expanded`, `aria-controls="site-menu"`) opens a full-screen dialog (`aria-modal`, `aria-label="Site menu"`) with focus trap, Escape to close (focus returns to the button) and scroll lock. Contents: **Find** list, **More** list (same items as desktop), an **Appearance** switch, then **Sign in** and **Get started**, or dashboard and **Sign out** when signed in. The menu closes on navigation.

### Footer

| Column         | Links                                                                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brand          | Logo, strapline "Property in Nigeria, checked before you commit.", Sureground on X.                                                                                       |
| Find           | Homes for sale, Homes to rent, Short stays, Land, Off-plan developments, Estates, Detty December, Renting a home (`/renters`), Buying property (`/buyers`).               |
| Own and manage | Sell a property, Let a property, Property management, Realtors and agencies, Pricing, How it works (`/#how-it-works`), Guides (`/resources`), Create an account, Sign in. |
| Contact        | Support email, phone and WhatsApp when configured, support hours, "Lagos, Nigeria", About Sureground.                                                                     |
| Legal bar      | Privacy, Terms, Cookies, Data protection (`/privacy#your-rights`), copyright.                                                                                             |

Each link column is a `<nav>` with its own label.

## 3. Signed-in workspaces

All under the `(dashboard)` route group, which adds a skip-to-main link, the session timeout guard and the add-role dialog. `getDashboardRoute` in `packages/shared/src/auth/constants.ts` sends each role to its home.

| Role (backend)                      | Web home              | Main areas (route segments)                                                                                                                                                            |
| ----------------------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Renter                              | `/renter/dashboard`   | discover, saved, applications, `properties/[id]/apply`, viewings, bookings, payments, maintenance, messages, roommates, trust score, referrals, notifications, settings, help          |
| Landlord                            | `/landlord/dashboard` | properties, units, listings, applications, tenants, leases, payments, deposits, arrears, maintenance, vendors, offers, shortlets, financials, notices, legal cases, microsite, billing |
| Property owner                      | `/owner/dashboard`    | properties, listings, offers, transactions, land (purchases, tours, per-plot analytics), shortlets, managed, invest, analytics, deposits, billing                                      |
| Buyer                               | `/buyer/dashboard`    | discover, saved, offers, viewings, tours, inspections, transactions, land purchases, representatives, invest, documents                                                                |
| Realtor                             | `/realtor/dashboard`  | listings, leads, clients, viewings, offers, commissions, collections, billing                                                                                                          |
| Agent (field, delegated)            | `/agent/dashboard`    | tasks, inspections, verifications, work orders, sync, bookings, managed                                                                                                                |
| Property manager (agency)           | `/agency`             | overview, owners, mandates, realtors, team, developments, handover, commissions, protection, performance, import                                                                       |
| Estate manager                      | `/estate/dashboard`   | households, dues, visitor passes, staff, amenities, governance, incidents, patrol, financials, microsite, marketplace                                                                  |
| Gateman                             | `/gateman/verify`     | verify, deliveries, vehicles, incidents                                                                                                                                                |
| Resident                            | `/resident/dashboard` | dues, visitor passes, announcements, maintenance, polls, amenities, directory                                                                                                          |
| Staff (admin, verification, fraud…) | back office           | `/admin/*` on web redirects to `apps/backoffice`.                                                                                                                                      |

Shared signed-in pages outside the role folders: `/representing`, `/listing-collections`, `/billing/return`, `/payments/return`.

The app (`apps/mobile`) mirrors this with `(market)` (public marketplace and listing), `(public)` (estate, landlord and development pages), `(auth)` and `(app)/(<role>)` groups with role-based bottom tabs, for example renter: Home, Discover, Applications, Messages, Account; buyer: Home, Discover, Offers, Messages, Account.

## 4. Indexing policy per route group

| Route group                                                                            | Sitemap                                                      | robots.txt                                                                                                                                                        | Page meta                                                                                         |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Brand, segment, seasonal, legal, `/resources`                                          | Yes, static list (priority 0.3–1.0)                          | Allowed (explicit allow for `/agents`, `/estates`, `/landlords`, `/renters`, `/buyers`)                                                                           | Own canonical                                                                                     |
| `/diaspora`, `/diaspora/transparency`                                                  | Only while the service is on                                 | Allowed                                                                                                                                                           | Canonical; 404 when off                                                                           |
| Market pages `/rent`, `/buy`, `/shortlets`, `/land`, `/developments`                   | Yes                                                          | `/shortlets?` and `/land?` disallowed                                                                                                                             | Unfiltered canonical; any query string (or page/state on developments) is `noindex, follow`       |
| Listing pages                                                                          | Up to 1,000 per market from the public API; developments too | Allowed                                                                                                                                                           | Slug canonical; `RealEstateListing` / `Accommodation` + `BreadcrumbList`; missing → 404 `noindex` |
| `/areas/[slug]`, `/resources/[slug]`                                                   | Only published areas / available guides                      | Allowed                                                                                                                                                           | Canonical + `BreadcrumbList`; unpublished → 404 `noindex`                                         |
| `/e/*`, `/l/*`, `/collections/*`                                                       | No                                                           | Allowed                                                                                                                                                           | Canonical when found; `noindex` when missing                                                      |
| `/listing-collections`, land consents / inspections / watch / reviews, `/representing` | No                                                           | Allowed                                                                                                                                                           | `noindex, nofollow`                                                                               |
| `(auth)`                                                                               | No                                                           | Allowed                                                                                                                                                           | `noindex, follow`                                                                                 |
| Role dashboards                                                                        | No                                                           | Disallowed: `/dashboard`, `/renter`, `/landlord`, `/owner`, `/buyer`, `/realtor`, `/agent`, `/estate`, `/gateman`, `/resident`, `/admin`, `/oauth`, `/magic-link` | Site default (no explicit noindex)                                                                |

Gaps worth knowing (not bugs today, because these pages need a session and render no private content to a crawler):

- `/agency/*` is not in the robots.txt disallow list (`/agent` does not prefix-match `/agency`), and the dashboard layout sets no `noindex`.
- `/land/disputes`, `/land/dossier/*`, `/land/representing/*`, `/billing/return`, `/payments/return` and `/agency-invite/claim` have neither a disallow rule nor `noindex`.

A one-line fix is a `robots: { index: false }` in `app/(dashboard)/layout.tsx` (it is a client component today, so it needs a server wrapper) and `/agency` in `robots.ts`.

## 5. Landing page specs

Shared structure (D2): `LandingHero` (eyebrow, serif `h1`, lead, two CTAs, photo) → content sections → optional `FaqList` → ink `ClosingBand` with two CTAs. Stock photos are labelled stand-ins and never illustrate a listing (D9).

### `/` — homepage

| Item            | Detail                                                                                                                                                                                                                                                                             |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Purpose         | Orient every visitor and start a search.                                                                                                                                                                                                                                           |
| Audience        | All, mainly renters and buyers.                                                                                                                                                                                                                                                    |
| Primary CTA     | Hero search (`HeroSearch`, area suggestions, routes to the market search with `?q=`). Closing band: **Get started**.                                                                                                                                                               |
| Secondary CTA   | **Browse homes** (`/rent`).                                                                                                                                                                                                                                                        |
| Sections        | 1. Hero "Property you can check before you commit" with search. 2. Recently listed (3 rent + 3 sale, hidden if none). 3. How Sureground works (rent, buy, short stays). 4. Search by area. 5. Trust and safety facts. 6. Diaspora feature (only when on). 7. FAQ. 8. Closing band. |
| Data            | Latest listings and area inventory from the public API, server-rendered with timeouts; areas from `components/home/areas.ts`; diaspora availability.                                                                                                                               |
| Structured data | `Organization` with `ContactPoint`; `WebSite` with `SearchAction` to `/rent?q=`.                                                                                                                                                                                                   |
